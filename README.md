**🔐 Keylogger – Keyboard Activity Logger (Educational Project)**

This project is a simple keylogger built in Python using the **pynput library**.
It demonstrates how keyboard events can be captured programmatically and logged into a file for learning, debugging, or authorized monitoring purposes.

**📌 Overview**

This keylogger listens to keyboard events at the system level and stores the keys pressed into a local file named logfile.

It captures:

    1. Alphabet keys
    
    2. Numbers
    
    3. Special characters
    
    4. Space and Enter
    
    5. Converts certain keys (like Shift, Ctrl, Alt) into empty strings so they do not appear in the log

The program runs continuously using **pynput.keyboard.Listener**.
